Built to solve the gaps in Kafka tooling.

We built Watermark because we were tired of choosing between extremes. On one hand, legacy tools like Offset Explorer are showing their age with outdated UIs and clunky UX.

On the other hand, modern web-based Kafka UIs look great, but miss the operational features needed for daily data engineering work, and they often time out on clusters with too many brokers.

So we built Watermark as a native desktop app: fast by default, no browser, no Docker. It adds the operational features DevOps and engineers actually need.

Install Watermark on macOS

Three steps and about a minute. The build is unsigned, so the last step clears the quarantine flag macOS adds to downloads.

  1. Download the disk image

    Get Watermark-darwin-universal.dmg, a universal build for Apple silicon and Intel Macs. Compare it with checksums.txt if you want to verify the download.

  2. Drag Watermark into Applications

    Open the disk image, then drag Watermark.app onto your Applications folder.

  3. Clear the quarantine flag

    Run this once in Terminal. Without it macOS reports the app as damaged, because the build is not notarized. xattr -cr /Applications/Watermark.app
